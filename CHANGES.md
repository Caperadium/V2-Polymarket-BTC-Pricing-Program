- Fix market-maker markout-deadlock quote shutdown (live 2026-07-14/15: 3 ladders, ~0 resting orders, 0 fills for 15h+). `pnl_report.markout_stats` returned the REGION ROLLUP's n_attempted when the measurement fell back to the rollup; once the wing (n=23, mk_avg -1.7c) and belly (n=22, -2.2c) rollups crossed markout_min_n=20 with negative averages, every cell of both regions counted as "attempted >= min_n", so the sizing W4 exploration carve-out closed fleet-wide: Kelly legs m-clamped to 0 AND presence floor gated off -> no orders -> no new fills -> the negative verdict could never be re-measured (self-locking). `markout_stats` now always returns the exact CELL's n_attempted (0 if the cell is absent) while keeping rollup semantics for mk_avg/mk_var/n -- a trusted-negative rollup still zeroes Kelly sizing, but unmeasured cells keep their presence-floor exploration probes flowing so calibration can update. Affects `market_maker/pnl_report.py`; tests updated + deadlock regression added in `tests/test_mm_pnl_report.py`. Full suite 765 passed.

- Fix market-maker dust orders (~1e-45 shares observed live across the 2026-07-20 ladder). Root cause: with a trusted measured-negative markout (wing region rollup n>=markout_min_n), the sizing haircut clamps m to 0 and calls `kelly_buy(price + 0, price)`; the Kelly formula's float rounding leaves a +/-1-ulp residue instead of exact 0, and a positive residue survives every downstream cap (caps only shrink sizes; all clamps compare with a +1e-12 tolerance) while the presence floor is gated off in exactly this case -- so the residue posts as a dust order. Two lines of defense: (1) `robustness_sizing.kelly_buy` now early-outs to exactly 0.0 when `belief_p <= price`; (2) `OrderLifecycleManager` gains `min_order_size` (default 0.0 = old behavior), threaded from `VenueDescriptor.min_size` (1.0) by the harness -- a quote side below the venue minimum is treated as no-quote and any resting order on that side is cancelled, matching what a live venue would accept. Affects `market_maker/robustness_sizing.py`, `market_maker/order_lifecycle.py`, `market_maker/harness.py`; tests added in `tests/test_mm_robustness_sizing.py` (exact-zero sweep over all tick prices + live 58k repro) and `tests/test_mm_order_lifecycle.py` (sub-minimum suppression + default-zero back-compat). Full suite 764 passed.
