- Fix permanent bankroll freeze from fair-value-anchor sanity-band false positives. `compute_fair_value`'s per-strike sanity band now checks the consensus against the SANITIZED (bucket-round-tripped) pricer/mid ladders instead of the raw inputs. Previously one crossed mid pair anywhere in a ladder (routine on thin far-expiry wing books; observed live on the VPS 2026-07-17 ladder, 72000 mid > 70000 mid) shifted the reconstructed ladder at every strike via the global bucket renormalization, guaranteeing a "per-strike sanity-bound violation" fallback on every recompute (1949/1949 on the VPS), so the anchor was never BEUOY, the harness's 20-clean-tick auto-unfreeze could never start, and the ladder's bankroll stayed frozen for its whole life (update_count=0). The consensus is provably a convex combination of the sanitized ladders, so the new band makes the check a pure numeric safety net; non-monotone inputs are repaired by the bucket transform and logged at debug with the deviating model id. Tests: repurposed the old non-monotone-pricer fallback test to the new BEUOY semantics, added the exact VPS crossed-wing production ladder as a regression test, an input-matching-monkeypatch test proving the fallback+freeze path still fires on a genuine band violation, and a frozen-state test documenting that the anchor never self-unfreezes (harness owns it).
